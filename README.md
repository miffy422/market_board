## 📊 多市场二级市场数据展板

### 📒 项目简介

<details>  
<summary>展开</summary>  
    本项目拟建设一套面向研究、投资与管理人员的多市场数据展板。展板以"每日17:00前"为固定信息截面，在同一界面集中呈现中国内地、香港、日本、韩国、美国主要指数，以及大宗商品与中美国债收益率曲线的涨跌、成交与市场特征，并同步汇总对二级市场具有实际影响的重要信息，形成可快速浏览、可追溯、可持续更新的日度市场总览。  
</details>

### 🚀 使用说明

<details>

<summary>展开</summary>

本项目通过 Streamlit 云端部署，无需本地环境，可通过浏览器直接访问。

**① 登录 Streamlit Cloud**

打开 [share.streamlit.io](https://share.streamlit.io)，使用 GitHub 账号授权登录。

**② 创建应用**

点击 **New app**，按以下信息填写：

| 配置项            | 填写内容                                       |
| :------------- | :----------------------------------------- |
| Repository     | `https://github.com/miffy422/market_board` |
| Branch         | `main`                                     |
| Main file path | `app.py`                                   |

**③ 部署并访问**

点击 **Deploy**，等待 1-2 分钟构建完成，即可访问页面

**④ 数据更新机制**

仓库中的 `market.db` 随仓库一起部署；GitHub Actions 每日（北京时间约 16:30）定时运行 `update_data.py` 并自动提交更新，云端页面数据次日自动刷新，无需手动干预。

> 💡 若需立即更新数据，可进入仓库 → **Actions** → **Daily Market Data Update** → **Run workflow** 手动触发，待其完成后在 Streamlit Cloud 页面右上角选择 **Reboot app** 即可。

</details>

### 📖 页面功能说明

<details>

<summary>展开</summary>

| 功能           | 说明                                                                             |
| :----------- | :----------------------------------------------------------------------------- |
| 日期切换         | 左上角下拉框选择历史日期，查看任意交易日的截面数据                                                      |
| 市场概览         | 六大市场代表性指数卡片（中国内地 / 香港 / 日本 / 韩国 / 美国 / 大宗商品，最新价 + 涨跌幅）                         |
| 分市场行情        | 中国内地 / 香港 / 日本 / 韩国 / 美国 / 大宗商品 六个标签页，含行情表格与涨跌幅柱状图                             |
| 当日盘面总结       | 全市场涨跌广度、各市场领涨领跌、重要信息统计，并对 |涨跌幅| ≥ 2% 的指数给出异常波动预警                               |
| 中美国债收益率曲线与利差 | 中/美 2Y·5Y·10Y·30Y 收益率曲线折线图、10Y-2Y 期限利差（含"倒挂=衰退信号"提示）、中美国债 10Y 利差，及明细表（含日变动 bp） |
| 图表下载         | 悬停图表，点击右上角工具栏 📷 按钮可下载 PNG 图片                                                  |
| 数据下载         | 每个标签页下方有"下载 CSV"按钮，国债收益率区块另有"下载国债收益率明细 CSV"，均可用 Excel 直接打开                     |
| 重要信息         | 按重要等级分色展示当日新闻，支持一键下载 CSV                                                       |

</details>

### 🔌 数据源

<details>

<summary>展开</summary>

| 数据                       | 来源                                                                | 说明                                                                                                                                       |
| :----------------------- | :---------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------- |
| A股 / 港股                  | 腾讯财经 `qt.gtimg.cn`                                                | 实时行情，由 `f43`(最新价) / `f60`(昨收) 计算真实价与涨跌幅                                                                                                  |
| 日本 / 韩国 / 美国 / 大宗商品      | **CNBC** `quote.cnbc.com`                                         | 海外品种统一走 CNBC 公开行情接口。期货连续合约：`@GC.1` 黄金 / `@SI.1` 白银 / `@CL.1` WTI原油 / `@HG.1` 铜 / `@S.1` 大豆 |
| 国债收益率（中/美 2Y·5Y·10Y·30Y） | 东方财富数据中心 `datacenter-web.eastmoney.com`（`RPTA_WEB_TREASURYYIELD`） | 一次请求返回中债 + 美联储收益率；**备用源**：美国财政部官方日度 CSV（仅补美国）                                                                                            |
| 新闻资讯                     | 东方财富 7×24 快讯 `newsapi.eastmoney.com`                              | 公开接口，无需登录/鉴权                                                                                                                             |


</details>

### 📄 文件说明

<details>

<summary>展开</summary>

| 文件名                                  | 作用                                                                        |
| :----------------------------------- | :------------------------------------------------------------------------ |
| `app.py`                             | 前端页面脚本（Streamlit），含市场概览、分市场行情、当日盘面总结、国债收益率曲线、重要信息                         |
| `update_data.py`                     | 数据获取和存储脚本（腾讯 / CNBC / 东方财富数据中心 / 东方财富快讯多源抓取）                              |
| `market.db`                          | 数据库文件，存储历史行情（表 `indices`）、新闻（表 `news`）与国债收益率（表 `yields`）                  |
| `requirements.txt`                   | 依赖清单（含 `streamlit` / `pandas` / `requests` / `beautifulsoup4` / `plotly`） |
| `.github/workflows/daily_update.yml` | 自动任务配置，每日定时运行 `update_data.py`                                            |

</details>
